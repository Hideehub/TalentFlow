# TalentFlow Documentation

Start here when trying to understand the application.

## Documents

- `APPLICATION_PROCESS.md`: full explanation of the current application process, modules, data flow, gaps, and recommended way forward.
- `FLOW_AND_ROLES.md`: shorter reference for screens, user roles, and access rules.
- `PRODUCT_MODEL.md`: product positioning, user types, dashboard visibility, candidate visibility, and future ownership model.

## Recommended Reading Order

1. Read `PRODUCT_MODEL.md` to understand what TalentFlow is becoming.
2. Read `APPLICATION_PROCESS.md` to understand the full product workflow.
3. Read `FLOW_AND_ROLES.md` when you need a quick role/access reference.
4. Use the "Recommended Way Forward" section in `APPLICATION_PROCESS.md` to decide what to build next.
